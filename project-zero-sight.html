Project detail

Zero-Sight Voice-Driven Email Application

Accessibility

This project was designed to support visually impaired users by creating a voice-driven email system. The central purpose was to make email communication more accessible and hands-free, reducing the dependency on a visual interface and enabling smoother interaction through voice commands.

The application concept focuses on empowering users to compose, read, and send emails using voice-based prompts and feedback. This aligns with my interest in building products that improve accessibility, independence, and daily productivity for differently abled users.

Key highlights

  • Architected a zero-sight voice-driven email application.
  • Built to enable users to send and listen to emails hands-free.
  • Improves accessibility and practical usability for visually impaired users.
  • Balances user experience, simplicity, and meaningful inclusion.
